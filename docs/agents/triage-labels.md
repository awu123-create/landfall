# Triage 标签映射

各工程 skill 使用 5 个标准 Triage 角色描述任务状态。本表定义标准角色与本仓库 GitHub Issues 实际标签名的对应关系。

| mattpocock/skills 标准角色 | 本仓库标签名 | 含义 |
| -------------------------- | ---------------- | -------------------------------------- |
| `needs-triage`             | `needs-triage`   | 待维护者评估范围与可行性 |
| `needs-info`               | `needs-info`     | 等待提单人补充必要信息 |
| `ready-for-agent`          | `ready-for-agent`| 规格与验收标准已明确，可交由 Agent 独立实现 |
| `ready-for-human`          | `ready-for-human`| 需要人工判断或实现 |
| `wontfix`                  | `wontfix`        | 不予处理 |

当某个 skill 提及上述角色（如“打上 AFK-ready triage 标签”）时，使用本表右侧对应的标签字符串。
